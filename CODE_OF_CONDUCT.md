# Code of conduct

Pointer contributors are expected to keep participation welcoming, respectful,
and focused on improving the project.

## Expected behavior

- Be respectful of different experience levels and viewpoints.
- Give actionable technical feedback without personal attacks.
- Protect API keys, account details, private conversations, and other sensitive
  information.
- Respect the project's independent status and do not imply endorsement by
  Anysphere.
- Accept maintainer decisions made to protect users, security, or project scope.

Harassment, discrimination, threats, doxxing, sexualized conduct, and sustained
disruption are not tolerated in project spaces.

## Reporting

Report community-conduct issues privately to the repository maintainers. Use a
private GitHub security advisory instead when a report involves a vulnerability
or exposed secret. Maintainers may remove content, restrict participation, or
ban participants when necessary.

This policy applies to repository discussions, issues, pull requests, and other
spaces where someone represents Pointer.
